# finapso-legal

Oficjalne repozytorium zawierające dokumenty prawne, regulaminy oraz **Politykę Prywatności (Privacy Policy)** dla aplikacji mobilnej **Finapso**.

## 🚀 Jak włączyć stronę na GitHub Pages?

1. Wypchnij plik `index.html` oraz `README.md` do głównej gałęzi (`main`).
2. Przejdź do zakładki **Settings** (Ustawienia) w tym repozytorium.
3. W menu bocznym po lewej stronie wybierz **Pages**.
4. W sekcji **Build and deployment** -> **Source** wybierz:
   - **Branch:** `main`
   - **Folder:** `/ (root)`
5. Kliknij **Save**.

Po 1–2 minutach strona będzie dostępna pod adresem:
`https://<twój-login-github>.github.io/finapso-legal/`

Ten link możesz bezpośrednio wkleić w **Google Play Console** w sekcji *Polityka prywatności*.
